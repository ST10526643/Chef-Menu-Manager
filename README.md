# Chef's Menu Manager

Chef's Menu Manager is a React Native mobile application designed to help restaurant owners and chefs manage their digital menu.

## Features

- Add new dishes
- View all menu items
- Store dish names, descriptions, courses, and prices
- Navigate between different screens
- Shared menu data using React Context
- Simple and user-friendly interface

## Technologies Used

- React Native
- Expo
- TypeScript
- Expo Router
- React Context API
